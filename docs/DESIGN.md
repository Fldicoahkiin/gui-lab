# 设计

一个自绘的界面框架。屏幕上的任何东西（字、图、形状、控件）都能按自己的真实轮廓松开、变形、再合回去；风格是可以换的材质。Rust + wgpu，同一份代码跑原生和网页（WebGPU，回退 WebGL2）。

这份文档是实现的依据。改设计先改这里。

## 0. 三条规矩

1. **没有方框。** 任何效果都按真实轮廓算（字形、形状、图片的边），不按文本框、不按格子。
2. **只有一种让东西动的办法。** 事件往场里放东西，场和每个实例自己的时间决定画面。组件不直接写动画。
3. **静止时收敛，变化时给足。** 指针经过文字，文字不变。停下来的界面是一张干净、可读的页面。

## 1. 流水线

```
view(state) → 界面树 → 布局(taffy + parley) → 场景(实例) ─┐
事件 → 命中 → 消息 → update(state)                        │
事件 → 场(波、指针、滚动速度…)                           │
                                                          ▼
          第一遍：实例原样画进中间图（ink、near）
          第二遍：材质读中间图和场 → 最终画面
          第三遍：标注层（可选）
```

### 1.1 描述（`el.rs`）

`El<M>`：`key`、taffy `Style`、内容（无 / 文字 / 图片）、填充、边框、`on_press: M`、`on_key`、`focusable`、`scroll`、子节点。视图是 `fn(&S) -> El<M>`，更新是 `fn(&mut S, M)`（Elm 式，消息是普通值）。没写 key 的节点用路径当 key。

### 1.2 布局

每次更新重建 taffy 树（先求对，再求快）。文字叶子用 parley 量：给定宽度，返回高度。单位是逻辑像素，字号任意，不要求等宽。输出：每个节点的绝对矩形和裁剪矩形。

滚动容器：`scroll` 的节点裁剪子节点，偏移量存在运行时里，按 key 记。

### 1.3 场景（`scene.rs`）

三种实例，同一个记录（80 字节）：`rect`、`uv`、`paint`（色调、强调色、透明度、种类）、`clip`、`extra`（边框宽、图片号、静态松开度、出生时间）。

- 字形：一个字一个实例。图集每个像素存两样：覆盖率、离最近笔画的近度（距离变换，12 像素内）。
- 形状：矩形，解析距离。填充或只有边框。
- 图片：一张纹理一个实例。

实例的身份是 `key + 序号`。第一次出现记下出生时间，材质据此让它凝结出来。文字内容变了算新实例。

### 1.4 两张中间图

- `ink`（RGBA8）：这里有什么。文字写色调，图片写原色，a 是覆盖率。
- `near`（RGBA8，取最大值混合）：r 离最近的墨有多近（按真实轮廓）；g 是不是图片；b 这个实例自己的松开度（出生、按下、悬停）；a 备用（实例编号低位，给标注层）。

WebGL2 不能每个目标各用一种混合，所以同一批几何画两遍，不用多目标。

### 1.5 场

现在：最多 8 道波前（位置、起始时间、强度）加指针，解析计算，作为 uniform。之后：一张低分辨率的场纹理在 GPU 上逐帧演算（能量、流向），输入加上滚动速度、拖拽、音频频谱。

事件到场的对应：

| 事件 | 放进场里的东西 |
|---|---|
| 按下 | 一道波前 |
| 指针移动 | 透镜（只松开图片和背景，不碰文字） |
| 按住不放 | 透镜持续增强，松开时放出一道波前 |
| 拖拽 | 沿路径的尾迹 |
| 滚动 | 按速度给整屏一个剪切 |
| 输入一个字 | 这个字形从松开凝结出来 |
| 提交（换页、切主题、切材质） | 从触发位置出发的一道波前，新旧状态以波前为界 |

### 1.6 材质

第二遍是一个全屏着色器。每个材质是一组函数：`loosened(p)`（松开时这里画什么）、`ground(p)`（背景）、`resolve(...)`（合成）。材质按“全局 + 实例覆盖”选择。所有参数是 `Fx` 里的数，一个参数一个名字、范围和步长。

### 1.6.1 图片怎么变成记号

图片松开时，是**图片自己变成记号**，不是在图片上面盖一层网格。规矩：

1. **记号之间露出来的永远是图片自己的暗部或黑，不是页面的底色。** 浅色主题下也一样。图片有自己的底。
2. **先像素化，再刻记号。** 第一步是无缝的色块：每一格取它底下的平均色，格与格之间没有缝。点距趋近 1 像素时，它就是原图。第二步才在每一格里画记号。
3. **深浅用“换记号”表达，不用“把形状缩小”表达。** 把亮度量化成几级（级数是参数），每一级对应记号表里的一个记号。
4. **记号表可换**，每张表是图集里的一排小图：
   - 色块抖动：实心、棋盘、疏点、密点（海报上那种低像素）。
   - 字符：按疏密排的一串字符。
   - 笔触：短线，方向跟着图片的明暗梯度走（草浪那种）。
   - 光点：带一圈辉光的点，暗处直接没有。
5. **上色方式**是参数：原色、单色（主题的墨色）、双色、指定色。
6. 可选：按亮度把记号向外推一点（有纵深的字符肖像）；辉光。

参数：图的点距、亮度级数、记号表、上色方式、底的暗度、方向跟随强度、纵深、辉光。

文字和形状没有自己的底，它们松开时露出的是页面，这是对的。

#### 实现

**记号图集**（`marks`，R8，启动时在 CPU 上生成，一次上传）：

- 一行是一张记号表，一列是一个亮度级，最多 16 级。每块 32×32 像素，四边可以无缝拼接。
- 色块抖动表：第 k 级 = 把 8×8 Bayer 阈值矩阵和 k/N 比较得到的黑白图案，放大到整块。第 0 级全空，最后一级全实。
- 字符表：用排版系统把候选字符各画一遍，**量出每个字符实际的墨量**，按墨量排序后等间隔取 N 个。不凭印象排疏密。
- 笔触表：一条短线，粗细随级数增加。方向不放进图集，由着色器旋转取样坐标。
- 光点表：径向衰减的圆，半径和亮度随级数增加，边缘是软的。

**参数**（`PicFx`，一个 uniform 结构；最多 8 组，实例用 `extra` 里的槽号选一组）：

| 名字 | 含义 | 范围 |
|---|---|---|
| `pitch` | 点距，逻辑像素 | 1–64 |
| `levels` | 亮度级数 | 2–16 |
| `set` | 记号表的行号 | 整数 |
| `colour` | 0 原色，1 主题墨色，2 双色，3 指定色 | 整数 |
| `ground` | 底的亮度：0 是黑，1 是这一格的原色 | 0–1 |
| `gamma` | 亮度到级数的曲线 | 0.3–3 |
| `spread` | 相邻两级之间用抖动过渡的宽度，0 是硬分级 | 0–1 |
| `follow` | 记号朝向跟随明暗梯度的强度 | 0–1 |
| `depth` | 按亮度把取样位置推开的距离，逻辑像素 | 0–24 |
| `glow` | 辉光强度 | 0–2 |

**着色器里，图片上的一个像素这样算**（`k` 是这里的松开度，0 到 1）：

1. `k = 0`：直接输出 `ink` 里的原色。结束。
2. 当前点距 `P = round(mix(1, pitch, smoothstep(0, 0.5, k)))` 个设备像素。`cell = floor(p / P)`。全屏共用一张格，所以相邻的图片和文字对得上。
3. 这一格的颜色 `c` = 在格内取 4 个点（`P > 16` 时取 9 个）对 `ink` 采样求平均。此时输出 `c` 就是无缝的像素化；`P = 1` 时等于原图。
4. 亮度 `L = dot(c, 0.299, 0.587, 0.114) ^ gamma`。级数 `n = floor(L * levels + (bayer(cell) - 0.5) * spread)`，夹在 0 到 `levels - 1`。
5. 格内坐标 `uv = fract(p / P)`。若 `follow > 0`：用上下左右四格的亮度差求梯度角 θ，把 `uv` 绕格心旋转 θ（乘以 `follow`）。
6. 记号 `m = marks[set][n](uv)`。
7. 墨色按 `colour` 取：`c`、主题墨色、两色之间按 `L` 插值、或指定色。底色 `g = c * ground`。
8. 这一格的结果 `r = mix(g, 墨色, m) + 墨色 * glow * 软化的 m`。
9. 输出 `mix(c, r, smoothstep(0.5, 1, k))`。前一半时间只变粗，后一半时间记号才浮出来。

`depth > 0` 时，第 3 步之前先把 `p` 沿“指向指针的方向”推 `L_上一帧估计 * depth`，得到随指针变化的视差。

**页面底色在这九步里没有出现过。** 这就是第 1 条规矩在代码里的样子：图片的像素只由图片自己的颜色、记号和黑算出来。

**验收**：浅色主题下把一张图完全松开，截图里图片矩形内不出现页面底色的像素（取样比对）；`pitch = 1` 且 `k` 任意时输出与原图逐像素相等（允许 1/255 的误差）。

### 1.7 标注层

第三遍，读排版结果画：每个节点的框、key、宽高、实例数；指针到命中节点的连线；中间图的缩略视图。数字全部是真的。

### 1.8 输入

指针位置 → 倒序命中 → 悬停 / 按下 / 焦点。Tab 轮转焦点，Enter 和空格触发。悬停和焦点的指示是四个角标，框住目标，在目标之间平滑移动。滚轮找最近的滚动祖先。

### 1.9 平台

- 原生：winit 窗口；离屏渲染出 PNG（`shot`）用于验收。
- 网页：一个 canvas。网页只负责转发指针、滚轮、键盘事件。无障碍镜像和输入法之后做（隐藏输入框接输入法，隐藏 DOM 树镜像给读屏）。

## 2. 参数必须能精确设置

不用滑块当主要手段。数字控件（`number`）：

- 显示当前值和单位；左右两个步进按钮。
- 获得焦点后直接键入数字，回车确认，Esc 取消。
- 上下方向键按步长改，按住 Shift 乘 10。
- 在数值上横向拖动可以连续调（辅助手段）。

`Fx` 的每个参数都通过它暴露：字的点距、图的点距、不规则度、错位、波速、波的寿命、波宽、尾长、推力、透镜半径、凝结时长。

## 3. 组件

按钮、数字控件、输入框、开关、滑块、标签页、列表、卡片、对话框、图片、分隔线、滚动区。

组件是普通函数，返回 `El<M>`。像 shadcn 一样以源码分发：每个组件一个文件，`registry.json` 列出文件和依赖，使用者把源码拷走自己改。

## 4. 风格 = 主题 × 材质 × 标注

- **主题**是数据：颜色、字号阶、间距、线宽、圆角。
- **材质**是第二遍的画法。
- **标注**是第三遍开不开、画什么。

一个“风格预设”是这三样加一组 `Fx` 的值。

| 预设 | 主题 | 材质 | 标注 | 怎么做 |
|---|---|---|---|---|
| Neo-Dotmatrix | 黑底、单色 | `dot` | 关 | 全局点阵；松开时每个点的大小是它底下墨的多少 |
| Lo-Fi Print | 纸色、两色油墨 | `print` | 关 | 半色调网点、套印错位、纸纹、墨的洇开（对 near 取阈值） |
| Glitch | 黑底 | `glitch` | 关 | 行带错位、通道错开、块位移、保持上一帧 |
| Metamorphosis Linocut | 纸色、单色 | `lino` | 关 | 墨 = 对 `near + 噪声` 取阈值，边缘像刀刻；沿等距线刻留白；两个状态的 near 插值就是形变 |
| Algorithmic / Digital Gaze | 黑底、等宽字 | 任意 | 开：框、编号、置信度式标签、追踪线 | 标注层 |
| Transparent Electronics | 半透明、冷色 | `xray` | 开：层 | 把中间图当成可见的层叠起来；near 的等距线当走线；层随指针有视差 |
| Tech-Manual | 网格纸、黑 + 一个信号色 | `plain` + 阴影线填充 | 开：引线、编号、尺寸线 | 标注层的另一种画法 |
| Normcore | 系统灰、默认字号 | `plain` | 关 | 只是主题 |
| Cyberminimalism | 近黑、发丝线、等宽 | `plain` | 关 | 只是主题 |
| Bauhaus | 三原色、几何形 | `plain` | 关 | 主题加几何形状组件 |
| Neo-Y2K 金属 / 立体 / 液态 | 银、渐变 | `chrome`、`liquid` | 关 | 把 near 当高度图求法线，用环境贴图着色得到浮雕金属；液态是对模糊后的 near 取阈值，相邻的字会粘连 |
| Mixed media | 拼贴 | 按实例混用 | 关 | 每个实例自己的材质，加纸纹和撕边 |

`plain` 材质也走两遍绘制，只是不松开；波、凝结、角标仍然在。

## 5. Gallery

用框架自己写，是一个应用：

- 左栏：组件列表、材质列表、场景列表。
- 每个组件一页：实时预览、全部变体、源码、可调的参数。
- 顶部两个全局切换：主题、材质。切换时变化从按钮的位置传开。
- 每个风格预设一页：一屏专门为它设计的界面，可以操作。

## 6. 展示场景

1. **开场**：满屏的点聚成标题，再散开拼出首页。
2. **读一篇文章**：图文混排的长文；拖动图片，文字绕着它的轮廓实时重排。
3. **一张图的印法**：在同一张图上移动指针，各种材质依次显现；点距当场用数字改。
4. **变形**：词散成粒子，拼成图；图合成按钮。
5. **透视**：按住一个键，界面被拆开，框、编号和中间图浮出来。
6. **声音**：频谱进入场，整页随低频起伏，文字仍然可读。
7. **十二种风格**：同一个界面，在第 4 节的预设之间切换，变化从点击处传开。
